# AppDev1 Final Practical Exam

## Final Reflection

Isa sa pinaka-challenging na part para sa akin was yung pag-setup ng Tailwind at shadcn/ui. Nagloko yung `npx` commands sa terminal ko (classic Windows environment issue) tapos nag-throw ng error na hindi mahanap yung executable file. Kinabahan ako nang malala kasi feeling ko maba-block na ako dun sa step na yun, pero thankfully, nagawan ng paraan by manually creating the configuration files and yung shadcn Input component mismo. Dun ko na-realize na mahalaga talaga na alam mo kung paano gumagana yung tools "under the hood" para kapag nag-fail ang terminal commands, alam mo kung paano i-troubleshoot manually.

Solid din yung process ng pag-extract ng design tokens at paglagay sa `root.css`. Mas naging malinis tingnan yung CSS modules ko after. Nakakatuwa na pwede mo palang i-combine smoothly yung traditional CSS approaches at modern libraries like shadcn/ui without breaking the design.
